# Decision history — how to write it (OKF)

This directory is the durable, navigable record of **what was decided and why** in this repo, in Google
Cloud's [Open Knowledge Format (OKF)](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md)
— markdown files with YAML frontmatter, one required field `type`, and reserved filenames — in the
**v0.2 dialect**: the v0.1 conformance rules plus a provenance field and a version declaration.

- **`log.md`** — the append-only ledger, newest-first. Reserved OKF file: **no frontmatter**. Every
  notable decision or operational action lands here as one entry:
  `## YYYY-MM-DD — title` then **Decision / Why / Alternatives / Provenance**.
- **`NNNN-slug.md`** — an ADR (Architecture Decision Record). OKF *concept* file: frontmatter with
  `type: ADR`. Write one ONLY when the decision is **hard to reverse, surprising without context, and
  the result of a real trade-off**. Otherwise a `log.md` entry is enough.
- **`index.md`** — the router. GENERATED by `okf index <dir>` — never hand-edit the body. Reserved OKF
  file: **no frontmatter**, except at the **bundle root**, which declares `okf_version: "0.2"` and
  nothing else. A *nested* `index.md` with frontmatter is a finding — it would read as a second root.
- **`README.md`** (this file) — the convention. OKF-exempt project doc.

**v0.2 provenance.** Every concept file records who produced it and when. `generated.at` is an ISO-8601
datetime with an explicit UTC offset for the last material content change represented by the file, not the
original decision date or a later non-material file touch:

```yaml
generated: {by: human:alice, at: 2026-07-26T12:00:00-03:00}
```

The `by` prefix is the actor — `human:<name>` (a person decided or reviewed it; an ADR is always this),
`process:<name>` (a deterministic job wrote it), or `<producer>/<version>` (a model wrote it, e.g.
`claude-opus-4/1.0` — provisional until a human is recorded). That prefix is what lets a reader tell a
reviewed document from a generated one; a timestamp alone cannot. Git records later non-material touches.

Gate: `okf verify decisions/` (format) + `okf index --check decisions/` (index freshness), enforced on
every commit by the pre-commit hook. Installed by `okf-bootstrap`; `okf` lives on PATH, never as a copy
inside this repo.
