# Build gcrdings from Meetily Community

gcrdings will begin as a fully rebranded fork of the MIT-licensed Meetily Community codebase, retaining its Tauri, Rust, and Next.js architecture. This reaches a reliable audio workflow sooner than rewriting the existing capture and transcription path in Swift, while keeping engineering focused on verifiable records, encryption, revision history, and agent handoff. A native rewrite is reconsidered only when measured limitations justify it.
